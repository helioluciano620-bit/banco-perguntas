# Banco de Perguntas Pessoais

Projeto final de Aplicações Web I. Aplicação para criar perguntas e respostas, organizá-las por categoria e estudar em modo de teste.

## Funcionalidades
- CRUD completo (criar, ler, atualizar e eliminar) com persistência em `localStorage` (chave `bank_questions`)
- Três abas: Todas as perguntas, Adicionar pergunta e Modo de teste
- Validação de formulário com mensagens de erro
- Filtro por categoria
- Modo de teste com pergunta anterior/seguinte, mostrar resposta e baralhar

## Estrutura
- `index.html`: estrutura semântica
- `css/style.css`: estilos e media queries
- `js/app.js`: lógica, DOM, eventos e armazenamento

## Como executar
Abrir `index.html` no navegador (ou usar a extensão Live Server do VS Code).
